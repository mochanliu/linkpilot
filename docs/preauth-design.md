# 预授权：设备还没到货，配置先做完

## 这件事为了解决什么

入网（enroll）只建立归属，不带任何配置——这条契约不能动。于是一台盒子到货的现场，
顺序只能是：先入网，再回控制台配基础配置，再发布，再等设备下一次心跳拉取。
客户真正想要的是反过来：货在仓库里就能把主机名、VPN、客户口、静态路由都配好，
工程师到场只做一件事——把盒子接通、输入入网码，配置自己下去。

预授权就是这条登记：租户管理员在控制台里先给一台**还不存在**的设备起名字、登记序列号、
放站点、写基础配置。配置只存在控制器上（草稿），页面上它与真实设备分列两处，
不会被算成「离线设备」「未上线」「待心跳」。

## 五条拍板（2026-10-29）

| | 决定 | 落在代码里的样子 |
| --- | --- | --- |
| D1 | 认领参数走 enroll 请求的新字段 | `wire.EnrollRequest.PreAuth`；`sr-agent -preauth 「索引」` |
| D2 | 建登记这一刻就占名额 | 名额 = 已入网 + 未认领，见下面的账本 |
| D3 | 索引对不上就拒绝并报错 | 403 + 中文理由，列出这一家能输入的正确索引；绝不回退成普通入网 |
| D4 | 认领不自动发布 | 绑定只是把草稿挪到 node 上，发布仍然是人手点的那一下 |
| D5 | 站点可以挂，隧道这轮不做；所有设备级配置跟着预授权走 | 基础配置挂登记；underlay 隧道仍以真实设备为端点 |

D3 的代价是现场的：入网失败必须当场能改。所以理由里带的不是「not found」，
而是这份登记里现在有哪些名字——工程师在机架旁边打电话时只有这个能用。

## 账本（D2）

```
已占用 = len(Claim.Serials) + len(Claim.Reserved)   <= Claim.MaxUses
```

`Reserved` 存的是预授权记录的 id。它必须是能回放的：状态文件重新加载时由
`normalizePreAuths` 从现存登记重建，登记一旦被撤销或认领就自然消失。留着一条
不再对应任何登记的 reservation，等于凭空吃掉客户一台设备的入网资格。

这条规则的直接后果：纸面设备多到占满名额时，真实盒子也会被拒之门外。页面上
必须把这两半分开说（「已入网 1 台 · 预授权占 1 个」），拒绝理由也要说清是哪一半
占掉的（「预授权未认领 1 个 = 2/2；先在控制台撤销一条预授权或提高名额」）。

## 认领是一次移动，不是复制，也不是发布（D4/D5）

`enroll` 带着索引进来时，控制器做四件事，顺序不能换：

1. 按索引 + 租户找到登记；序列号登记过就必须与设备自报的一致；
2. 站点从登记移到 node（`node.site_id`），地图上的位置跟着走；
3. 草稿从 `PreAuthConfigs["tenant|pa_id"]` **移动**到 `Configs[configKey]`，
   版本号原样保留——客户看到的「草稿 v3」在认领之后还是 v3；
4. 释放这条 reservation，占位改成真实 serial。

版本号和「只有一份草稿」是这里的全部意义：两边各留一份，就会出现两个都能保存、
各自往前走的编辑器，而设备只会读到其中一个。所以认领之后再写这条登记是 409，
页面上那条登记也从此只读（状态变成「已认领 · node-N」）。

认领之后配置仍然没有发布：`published_version` 这个键压根不存在。什么时候重启盒子
由现场决定，控制器不替他做这个决定——这条与真实设备的发布模型完全一致。

## 索引的权限含义

入网码决定这台盒子属于哪个租户，索引只决定它认领这一家里的哪一条登记。名称唯一性
与解析都在租户范围内（`nameTakenLocked` / `preAuthByNameLocked`），所以索引不需要
任何额外授权，也拿不到别家的东西；反过来说，索引输错的后果是配置跑到同租户的另一台
盒子上，这就是序列号字段存在的理由，也是 D3 宁可对不存在的事务硬拒绝的理由。

## 控制台入口

- 资产 › 设备 › 「预授权（还没到货的设备）」：建登记、改名称/站点、撤销、写配置。
  「配置」这一列用的是登记行带回的 `config_version`：没保存过写「未配置」，
  保存过写「已配置 · 草稿 vN · 多久前 · 谁」。
- 基础配置页是双目标的：设备列表里真实设备显示 `node-N · 序列号 · 状态 · 站点`，
  登记显示 `预授权 名称 · 序列号 · 等待设备 · 站点`。选中登记时只有「保存草稿」，
  没有「发布到设备」也没有「下载配置包」，因为接收方还不存在。
- 资产 › 入网授权：名额列显示两半，序列号列列出「预授权等待认领：…」。
