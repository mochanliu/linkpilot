## 4. 对外必须说清的限制与口径

- **FEC 与 QoS 整形不要同时配**（owner 拍板：产品说明，不做硬校验）。FEC 是牺牲带宽补丢包，
  队列整形是补带宽不足，带宽不够时再牺牲带宽是自相矛盾的方案。
- **非对称回程不支持**：一条隧道只有一条中转链，回程按同一条链反向走；要不同的回程路径就建第二条隧道。
- **中转链上限 3 跳**，且多跳只在平面二层 lab 端到端实测过；本次回程方向修正之后**未**在分层拓扑复测
  双向 trace（现网全部是直连隧道，无客户影响）。
- **FEC 默认关闭**（控制台不勾、API 不带、插件零开销直通），已从五层逐层确认。
- 控制器二进制无版本号参数；识别代际用构建哈希，升级/回退按
  [`controller-ha-deploy.md`](controller-ha-deploy.md) 与 [`agent-handover.md`](agent-handover.md) §5.2。
